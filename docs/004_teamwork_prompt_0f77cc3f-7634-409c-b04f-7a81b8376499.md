Membangun halaman admin khusus (Dashboard CMS) pada proyek NeoBlog yang sudah ada untuk mengelola draf artikel dan moderasi komentar, sebagai fitur produksi bagi pengelola dan editor situs.

Working directory: d:\neoblog
Integrity mode: demo
The team must NOT: Copy code from existing open-source projects for core logic; Run external scripts or delegate execution to other tools.

## Requirements

### R1. Halaman Admin & Kontrol Akses Berbasis Sesi
Menyediakan halaman admin khusus untuk Dashboard CMS yang dilindungi oleh mekanisme login berbasis sesi dan kontrol akses berbasis role (seperti `admin` / `editor`) agar hanya pengguna berwenang yang dapat mengakses dashboard serta endpoint pengelolaan dan moderasi.

### R2. Pengelolaan Draf Artikel
Menyediakan fitur pengelolaan draf artikel pada halaman admin. Ruang lingkup detail aksi siklus hidup artikel (seperti pembuatan artikel baru, penyuntingan, pemfilteran status, penerbitan/pengarsipan, atau penghapusan) dibiarkan terbuka untuk diputuskan oleh tim.

### R3. Moderasi Komentar
Menyediakan fitur moderasi komentar pada halaman admin yang mencakup kemampuan melihat dan memfilter komentar berdasarkan status persetujuan (disetujui maupun menunggu/tersembunyi), menyetujui komentar, menyembunyikan/menolak persetujuan komentar, membalas komentar, serta menghapus komentar.

### R4. Kepatuhan Arsitektur Native Tanpa Dependensi Eksternal
Seluruh implementasi harus mengikuti tumpukan teknologi NeoBlog yang sudah ada secara 100% native tanpa dependensi eksternal (PHP native, MySQL/PDO, Vanilla CSS, dan Vanilla JS). Catatan trade-off: seluruh komponen UI, routing, autentikasi, dan pengujian harus dibangun secara mandiri tanpa pustaka atau framework pihak ketiga.

## Verification Resources

## Acceptance Criteria

### Autentikasi & Keamanan Admin
- [ ] Pengguna yang belum login atau tidak memiliki role berwenang ditolak aksesnya ke halaman Dashboard CMS dan endpoint mutasinya, sedangkan pengguna berwenang dengan kredensial valid dapat login melalui sesi dan mengakses dashboard.
- [ ] Seluruh aksi mutasi pada Dashboard CMS (login, pengelolaan draf artikel, dan moderasi komentar) menerapkan proteksi CSRF dan sanitasi input/output sesuai standar keamanan aplikasi NeoBlog yang sudah ada.

### Pengelolaan Draf Artikel
- [ ] Pengguna berwenang dapat melihat dan mengelola draf artikel melalui halaman Dashboard CMS dengan perubahan status maupun konten tersimpan secara persisten di basis data dan tercermin konsisten di sisi admin maupun publik.

### Moderasi Komentar
- [ ] Pengguna berwenang dapat memfilter komentar berdasarkan status persetujuan, menyetujui komentar, menyembunyikan/menolak persetujuan komentar, mengirim balasan komentar, dan menghapus komentar melalui halaman Dashboard CMS, dengan seluruh perubahan tersimpan persisten di basis data.

### Kepatuhan Teknologi & Pengujian
- [ ] Tidak ada dependensi eksternal maupun paket pihak ketiga yang ditambahkan ke proyek.
- [ ] Suite pengujian native (`php tests/php/runner.php`, serta `node tests/js/runner.js` jika relevan) berjalan dan lulus seluruhnya, mencakup kasus uji baru untuk kontrol akses admin, pengelolaan draf artikel, dan moderasi komentar, serta verifikasi independen mengonfirmasi seluruh alur berfungsi tanpa regresi.
